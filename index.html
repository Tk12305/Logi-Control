Logi Control

A native Linux control panel powered by Solaar and BlueZ.

Supported devices: Logitech mice and keyboards recognised by Solaar. Options+ is Windows/macOS-only — this app provides its Linux equivalent for discovery, receiver pairing, battery status, and supported hardware settings.
—

MOUSE CONTROLS

Hardware settings

Changes are written to the mouse through Solaar and persist across restarts. Scroll/button diversion is intentionally excluded: it is for advanced Solaar Rules and needs additional Wayland permissions.

KEYBOARD CONTROLS

Hardware settings

Keyboard settings are applied through Solaar. Key remapping and per-key rules remain in Solaar's Rule Editor. Some keyboards require Fn+Esc to toggle Fn-swap if the software setting has no effect.

DEVICE CONTROLS

No configurable settings

The selected device does not expose hardware settings that Logi Control can change safely. Use Open Solaar for pairing, key diversion, and advanced configuration.

With your Logi Bolt receiver connected, use Open Solaar to pair devices and change the settings that Solaar detects. This app keeps the safe system status in one place.

    

    

      
Advanced controls

      
Use Solaar for receiver pairing, supported button actions, gesture rules and per-device settings. In Wayland, button-diversion rules require extra permissions; the app keeps them separate so ordinary scrolling and buttons continue to work.
