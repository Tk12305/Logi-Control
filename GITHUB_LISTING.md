# GitHub listing

## Repository name

`logi_control`

## Short description

An unofficial Electron control panel for Logitech Bolt and Unifying devices on Arch Linux, powered by Solaar and BlueZ.

## Suggested topics

`arch-linux` · `logitech` · `solaar` · `electron` · `logi-bolt` · `mx-master` · `linux-desktop` · `bluetooth`

## About text for the first release

Logi Arch Control is an independent Linux control panel for supported Logitech devices. It wraps the proven device-management capabilities of Solaar with a simple Electron interface for device status, diagnostics, and safe hardware settings. Initial testing focuses on the MX Master 3S with a Logi Bolt receiver on Arch Linux.

## Suggested release title

`v0.1.0 — MX Master 3S / Logi Bolt on Arch`

## Suggested release notes

- First public release for Arch Linux.
- Device discovery and Logi Bolt receiver status via Solaar.
- MX Master 3S controls for DPI, SmartShift, scroll-wheel mode, and scroll direction where reported by the device.
- Desktop launcher installer; no npm dependency required at runtime.
- Known limitation: advanced rule-based remapping has extra Wayland permission requirements and is not part of the default interface.
